# מסע אומן — Uman Journey

משחק תלת־ממד לדפדפן: שביל לילי אל ציונו של רבי נחמן מברסלב באומן, פנים
הציון עם **תצלומים אמיתיים מן המקום**, וספרייה שמושכת את הספרים
**מספריא (Sefaria)** ומקריאה אותם בקול. עברית, אנגלית וצרפתית.

---

## הרצה

התצלומים והטקסטים נטענים בזמן ריצה, ולכן צריך שרת — פתיחה ישירה של
הקובץ מ־`file://` תיחסם על ידי מדיניות ה-CORS של הדפדפן.

```bash
python3 -m http.server 8000
# ואז http://localhost:8000
```

| סביבה | מה עובד |
|---|---|
| דסקטופ | הכל חוץ מג׳ירוסקופ. תנועה ב-WASD / חיצים, מבט בגרירת עכבר, `Esc` סוגר מסך |
| מובייל על HTTP מקומי | הכל חוץ מג׳ירוסקופ (iOS דורש HTTPS) |
| מובייל על HTTPS | הכל, כולל `DeviceOrientationEvent.requestPermission()` |
| בלי אינטרנט | הכל. הטקסטים באים מ-`data/texts.js`, הגופנים נופלים לסריף מערכת |

## התצלומים

15 תצלומים אמיתיים של הציון באומן, כולם מוויקישיתוף — בנחלת הכלל או
ברישיון Creative Commons. **הקרדיט המלא ב-[CREDITS.md](CREDITS.md)**,
ובתוך המשחק כל תצלום מוצג עם שם הצלם, הרישיון וקישור לדף המקור.

איפה הם מופיעים:

| מקום | תצלומים |
|---|---|
| לאורך השביל | האוהל שעל הקבר לאורך הדורות — סוף המאה ה־19 ועד ימי הסליחות של ראשית המאה ה־20 |
| בחצר, לפני הכניסה | היכל הציון והשער כפי שהם היום |
| **בפנים הציון** | מצבת רבי נחמן עצמה, אולם התפילה, המעבר המקורה, תפילה על הציון |
| בספרייה | חדר הלימוד שליד הציון, והקלויז של רבי נתן |

הקשה על תצלום ממוסגר פותחת אותו במלואו, עם הכיתוב והקרדיט.

## הספרים

כל עמוד בקורא מצביע על `ref` אמיתי בספריא. בפתיחת עמוד המשחק:

1. מציג **מיד** את מה שיש — עותק שמור ב-`localStorage`, ואם אין, הטקסט
   המוטמע ב-`data/texts.js`.
2. מושך **במקביל** גרסה טרייה מ-`https://www.sefaria.org/api/v3/texts/…`
   ומחליף אותה על המסך כשהיא מגיעה.
3. אם אין רשת — נשאר עם מה שיש, בשקט.

שורת המקור מתחת לטקסט אומרת בכל רגע מאיפה הוא הגיע (נקודה ירוקה = חי,
חומה = עותק שמור), ומקשרת לדף בספריא.

אם ספריא לא מחזיקה תרגום בשפת המשחק — כמו רוב הצרפתית — העמוד נופל
לאנגלית ואז לעברית, ואומר זאת במפורש בשורת המקור. עמוד ריק לא מוצג לעולם.

**ההקראה** משתמשת ב-`SpeechSynthesis` של המכשיר. לפני ההקראה הטקסט מנוקה
מטעמי מקרא, מהפניות בסוגריים ומסימני פרשה, ומפוצל למשפטים כדי שאפשר יהיה
לדלג. הקול נבחר לפי שפת הטקסט המוצג — כך שעמוד שנפל לאנגלית יוקרא בקול
אנגלי, גם כשממשק המשחק בצרפתית.

### להוסיף או להחליף ספר

לערוך את `data/books.js` (ה-`ref` הוא בדיוק כפי שספריא כותבת אותו), ואז:

```bash
python3 tools/fetch-texts.py
```

בלבד — אותו תוכן, בלי הרענון החי. לאירוח שבו גם המשיכה החיה מספריא עובדת,
ראו את גרסת ה-Pages שלמעלה.

## פיתוח

```bash
node --check game.js sefaria.js          # בדיקת תחביר
python3 -m http.server 8123 &
npm install --no-save playwright
node tools/smoke-test.js                 # 19 בדיקות בדפדפן אמיתי
```

`window.__uman` נחשף לצורכי פיתוח: `cam()`, `goto(x,z,yaw)`, `state`,
`openBook(i)`, `showPhoto(key)`.

### מוסכמות

- הערות בעברית, מזהים באנגלית. ES5+ בלי modules — הכל scope אחד ב-`bootUman()`.
- שלוש סצנות (`sceneOut` / `sceneTz` / `sceneLib`) מתחלפות בהחלפת המשתנה
  `scene` והזזת המצלמה; אין unload.
- `S.paused` מקפיא את התנועה בכל פעם שנפתח מסך מודאלי. חובה להדליק אותו
  בכל מסך חדש, אחרת השחקן "נוסע" מאחורי המסך.
- טקסטורות פרוצדורליות נוצרות ב-canvas (`tex()`); התצלומים בלבד הם קבצים.
- **צבעים**: three r128 אינו מפענח ערכי `color` מ-sRGB. כל צבע חומר חייב
  לעבור דרך `col()`, אחרת גוונים כהים ייצאו בהירים בהרבה מהכוונה.
- הסצנות נבנות רק אחרי בחירת שפה, כי כותרות הספרים והשלטים נצרבות
  לטקסטורות. החלפת שפה תוך כדי משחק עושה `location.reload()` — זה מכוון.
